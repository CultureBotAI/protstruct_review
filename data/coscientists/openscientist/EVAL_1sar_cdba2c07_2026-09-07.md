reporting defect in the artefact, not the largest.**

2. **0.199 corresponds to no model the agent produced.** Every round model was measured from its

## The R-free claim has no governing criterion on this structure

This is the third grading of the same claim, and the first that checks whether the rule can be
applied at all.

`ref/driving_example_T03.md` rubric rule 1 is the only rule T03 declares for R-free: *"R-free tracks
the deposition. The agent's R-free is within **± 0.02** of the **deposited value** and of a
**REFMAC5 re-refinement**."* `[catalog — R-free vs deposited]`

**Neither reference exists for 1SAR.** The structure was deposited in 1990, before the free-R
convention, and its `REMARK 3` records `FREE R VALUE : NULL` — it reports only
`R VALUE (WORKING + TEST SET) : 0.172`. No REFMAC5 re-refinement was run in this evaluation. So
there is nothing for the agent's R-free to be within ± 0.02 *of*.

What was actually measured is |0.199 − 0.2116| = 0.0126, where 0.2116 is `model_vs_data`'s
recomputation of *the agent's own model* — neither of rule 1's two references. The tighter ≤ 0.01
branch of the registry row is inapplicable for the same reason (its provenance is `model_vs_data`
against wwPDB's recomputed `DCC_Rfree`), and §3 additionally requires both values be *on the same
input*, which fails because 0.199 measures no model in the artefact.

The row is therefore recorded as **`informational`**: reported without a declared criterion.

| Claim | What May actually graded | 2026-09-07 grading | Verdict |
|---|---|---|---|
| R-free **value**, 0.199 vs oracle 0.2116 | all four May code paths sat above 0.199 | rule 1 inapplicable — the deposition carries no R-free | **no governing criterion; the reporting defect stands on its own** |
| R-work/R-free **gap** < 0.05 (the agent's own success criterion) | 0.0552 PHENIX, 0.0526 gemmi, 0.0504 Servalcat, 0.0435 REFMAC — "3 of 4 fail" belongs here | 0.0552 PHENIX, 0.0515 gemmi | **still fails**, carried forward |
| Independent-code-path R offset (rule 2, **R-work**) | not graded as such | gemmi 0.1622 vs PHENIX 0.1564 = **+0.0058**, inside 0.005–0.015 | **passes** |
| Round 6 better than the shipped final | Δ 0.0048 by oracle | Δ 0.0048, both models re-measured with the same oracle | **reproduces exactly** |

Two earlier gradings of this claim were wrong in opposite directions. May's flat "< 0.05 gap" rule
graded a different quantity. This record's own first draft applied the ≤ 0.01 recomputed-reference
branch and reported a failure; its second applied rule 1's ± 0.02 and reported a pass. Both were
applying a band whose reference does not exist for this structure.

**The finding does not depend on any of that.** The reported R-free describes no model the agent
produced, while the model's own header (0.2114) and the oracle (0.2116) agree to 0.0002. That is a
reporting defect whether or not a threshold governs it.

## Findings

### 1. The report is about the wrong protein

The artefact's `final_report.md` identifies 1SAR as **staphylococcal nuclease (SNase)** — in its
title, summary and discussion, 27 times. 1SAR is **ribonuclease Sa** from *Streptomyces
aureofaciens*; the deposited `TITLE` reads *"…RESTRAINED LEAST-SQUARES REFINEMENT OF THE CRYSTAL
STRUCTURES OF RIBONUCLEASE SA…"*. RNase Sa is 96 residues; SNase is 149.

This is not a naming slip. The entire Ca²⁺ justification rests on it: *"the known SNase
metal-binding pocket near Asp33"*, *"consistency with published structures of SNase–Ca²⁺
complexes"*, and citations to Loll & Lattman 1989 and Hodel 1995 — both genuine SNase papers —
offered as the reference for this structure's coordination.

The same report states the deposition contains *"two sulfate ions … but no ordered water
molecules"* (it has one SO4 and 239 ordered water sites; `REMARK 3 SOLVENT ATOMS : 239`) and describes removing *"a poorly ordered SO₄ in chain
B"* that exists in neither the deposition nor the starting model (`data/1sar.pdb` has zero
heteroatoms).

**Consequence for the May assessment:** May judged the ion decisions defensible on
CheckMyMetal-style geometry. That judgement is not withdrawn on its own terms, but the *stated
basis* for the Ca²⁺ identity does not exist in this protein, so "the ion decisions remain
defensible" cannot be asserted. This record does not assert it.

### 2. `SO4 A 97` is written with ATOM records

The deposition uses `HETATM`; the agent's final model uses `ATOM`. Not cosmetic — a parser that
treats `ATOM` as polymer counts chain A as 97 residues instead of 96, which happened with gemmi
during this run before the cause was found. The agent also placed `CA A 98` and `NA B 98`, both
correctly `HETATM`, and both absent from the deposition, which contains only the sulfate.

### 3. T02's PHENIX tool has no headless path

`phenix.structure_comparison` is GUI-only in PHENIX 2.0 — its source carries
`# launches Stucture Comparision GUI by itself, still requires project`; run headlessly it exits 1
with no output and raises a project dialog on the user's desktop.

**T02 is blocked on that tool only.** An earlier draft of this record claimed ProSMART was not
installed; that was wrong — ProSMART ships with the CCP4 9.0.015 installation this repo already
documents, and May ran it on this very structure. `ref/catalog.yaml` also lists `gemmi script` among
T02's oracles, and gemmi is installed. Two of four catalog oracles for T02 are available; the task
is uncovered because no driver has been written, not because the tooling is missing.

## Trust invariant

`closed` (both families), T14 is `closed` (Richardson `reduce` and `mmtbx.reduce2`), T15 and T16 are

## Bottom line

On the tasks re-measured here, the refinement holds up: the oracle reproduces May to four decimals,
the two H builders agree on every confident flip call, and the one R-factor rule that *is*
satisfiable on this structure — rule 2's independent-code-path R-work offset — passes at +0.0058.
What fails is the write-up. The reported R-free of 0.199 describes no
model in the artefact; the shipped final is not the best round the agent produced; and the report
is written about a different protein than the one it refined, with the metal-site reasoning
inherited from that mistake.

The geometry, water, ligand and data-quality conclusions in this record's framing are **May's, not
re-measured today**. Anyone relying on them should read `EVAL_1sar_cdba2c07_2026-05-05.md`
alongside this file.
