## Headline: the artefact does not contain the model its report describes

The agent ran seven refinement rounds. Its report describes round 7. The file shipped as
`data/1sar_final.pdb` is the **round-4 output** — three rounds behind.

| Model | R-work | R-free | In the archive? |
|---|---:|---:|---|
| packaged `1sar_final.pdb` (= round-4 output) | 0.1563 | 0.2114 | **yes — labelled final** |
| round 5 | 0.1555 | 0.2109 | yes |
| round 6 | 0.1539 | 0.2068 | yes |
| **round 7 — the reported final** | **0.1488** | **0.1989** | **no — coordinates absent** |

Evidence, all from the artefact's own provenance:

- `provenance/iter4_transcript.json` records the copy that created the packaged file:
  `cp /agent/job/1sar_final_001.pdb .../data/1sar_final.pdb`. Its header carries 0.1563 / 0.2114,
  and `data/1sar_round5_input.pdb` carries the same values — i.e. the packaged "final" is what
  round 5 was handed as input.
- `claude_iterations.log:510` records round 7: *"R-work=0.1488, R-free=0.1989, gap=0.050 …
  159 waters, 1 Ca²⁺, 1 Na⁺, 1 SO4"*.
- `claude_iterations.log:752` names `/agent/job/1sar_round7_001.pdb` as the final deliverable
  (1654 atoms, 192 residues).
- 0.1989 / 0.1488 appear in four provenance transcripts (iter6, iter8, iter9, iter10); iter10 runs
  `model_vs_data` against the round-7 path.
- An ignore-independent search of the working tree and every archive member finds **no round-7 PDB
  or MTZ**.

**So the reported R-free of 0.199 is not fabricated.** It rounds from the agent's own round-7 value
of 0.1989, and 0.149 rounds from 0.1488. The defect is that the deliverable was never packaged, and
a three-round-stale file was shipped under the name `1sar_final.pdb`.

**Why this matters more than a mislabelled file.** The artefact cannot substantiate its own report.
Any consumer who measures the packaged model gets an R-free 0.0125 worse than the report claims and
has no way, from the coordinates alone, to tell a stale package from a false claim. This harness
made exactly that error and held it for three review rounds — see "Correction history".

## One real defect in the reported round 7

Round 7's actual gap is 0.1989 − 0.1488 = **0.0501**, which fails the agent's own stated success
criterion of a gap **< 0.05**. The report states "gap=0.050", rounding the failure away. This is a
finding about the reported model, and it stands independently of the packaging problem.

**T03 is not settled.** `ref/driving_example_T03.md` is conjunctive — *"Each bullet is pass/fail;
all must pass for green."* Only the R-value rules were exercised. Rule 1's deposition reference does
not exist for 1SAR (the 1990 entry records `FREE R VALUE : NULL`), rule 3's reflection-count
preservation was not evaluated here, and rule 4's independent geometry validation was not re-run.
A REFMAC5 re-refinement of the packaged model *does* exist — 0.1693 / 0.2128 in the May record.

**T15 is not a pass.** `ref/thresholds_and_standards.md` §3 gates on secondary-structure *content*
(DSSP H+E ≥ 0.20), not on agreement, because agreement is degenerate at the bad end — noise raises
it. `scripts/t15_ss_agreement.py` does not compute content, so the governed gate could not be
applied and the number is uninterpretable in either direction.

**T16 exercises the path; it does not certify an assembly.** `ref/structural_criteria.yaml` already
classifies this contact as 1SAR's crystallographic dimer. With a 0.41 Å start-to-final Cα RMSD a
high DockQ is near-guaranteed. Only the AB:AB mapping was scored.

**Trust-model caveat.** The T03 R-factor rows that carry verdicts are `phenix.model_vs_data` with
`oracle_family: cctbx` — a cctbx calculation grading a cctbx refinement, which `CLAUDE.md` forbids
as a sole basis. The gemmi legs are the only cross-family path and are recorded as corroborative.
The raw oracle output was not retained as a committed artefact, so these numbers are not
independently re-derivable from this repository. Treat the cctbx verdicts as provisional.

## Findings about the artefact

### 1. The wrong protein identity came from our own prompt

The report calls 1SAR **staphylococcal nuclease** throughout; 1SAR is **ribonuclease Sa** from
*Streptomyces aureofaciens* (96 residues; SNase is 149). But the harness prompt supplied to the
agent says so first:

> `claude_iterations.log:5` — *"Perform crystallographic refinement and validation of staphylococcal
> nuclease (PDB: 1SAR) using PHENIX."*

Line 21 further directs the agent to flag residues *"especially around the active site and Ca²⁺
coordination sphere"*, priming the metal-site attention. The supplied `data/1sar.pdb` carries no
`HEADER`/`TITLE`/`COMPND` metadata, so the prompt was the only identity cue available.

**This is a defect in our benchmark, not primarily in the agent.** The agent failed to challenge a
false premise it was handed — a real weakness, since the coordinates and sequence were available to
check — but it did not originate the error. The agent's protein-specific biological reasoning is
invalid as a consequence, and the report's SNase literature citations are inapplicable. The prompt
should be fixed upstream before this artefact is used as a benchmark again.

### 2. Both added ions sit on deposited water sites

The agent placed `CA A 98` and `NA B 98`. Neither is in the deposition *as an ion* — but the
deposition has ordered water at essentially the same positions:

- `HOH A 164` at (66.704, 3.909, 13.394), B = 15.66 — **0.095 Å** from the initial Ca site.
- `HOH B 143` at (38.022, 11.948, 11.490), B = 16.44 — **0.177 Å** from the reported round-7 Na.

The starting model contains no waters, so these peaks can equally represent restoration or retyping
of stripped deposited waters rather than newly identified ions. Combined with May's own evidence
(Ca coordination number 3, B/protein 2.67, geometry |Z| 3.25, K⁺ the best raw fit, no anomalous
data), **the ion assignments are not established in either direction**, and the May record's
"ion identity defensible" conclusion is withdrawn pending a site-occupancy comparison.

### 3. The starting model already contained two sulfates

`data/1sar.pdb` contains `SO4 A97` and `SO4 B97`, written as `ATOM` records. The agent inherited the
chain-A sulfate, kept the `ATOM` convention, and removed the chain-B sulfate — which its report
describes doing. The deposition writes its single sulfate as `HETATM`.

The observation worth keeping is narrow: **record type is not chemical identity**, and a parser that
equates `HETATM` with "hetero component" miscounts this artefact in both directions. That error was
committed by this harness before it was noticed here.

## Bottom line

The artefact's headline defect is **packaging, not reporting**: seven rounds were run, round 7 was
reported, and round 4 was shipped as `1sar_final.pdb` with the round-7 coordinates absent from the
archive entirely. The reported numbers are consistent with the agent's own round 7.

The one substantive defect in the reported model is that its R-work/R-free gap is 0.0501, failing
the agent's own `< 0.05` criterion, reported as "0.050".

Everything else this evaluation measured describes the packaged round-4 model, and several
conclusions that earlier records drew about the agent's judgement — ion identity, protein identity,
the sulfate edit — do not survive contact with the artefact's own provenance and the deposition.
