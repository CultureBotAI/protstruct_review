These are static schema defaults, not a universal effective configuration across invocation surfaces.
2. **GUI initialization order and manual controls (`V4`, `#1221`; `wxGUI2/Programs/Refine/Main.py:17, 53–74, 81–166`, `Config.py:307–328`, `Dialogs.py:30–76`):**

   - `OptionsPage` (`Config.py:307–328`) and `Dialog_refinement_refine_adp_individual` (`Dialogs.py:30–76`) provide manual GUI controls and atom-selection helpers rather than an automated resolution-profile selector. The inspected planner block alone does not prove how a downstream caller selects between primary and backup commands at runtime, and an invalid command can still reach the return path (`:1340–1342`).

Because `construct_command_mechanically` includes `xray_data.r_free_flags.generate=True`, flag preservation is a provenance compatibility check for future trials rather than proof that existing MTZ flags are regenerated at runtime. 4. **Anisotropic ADP demotion vs. bundled FAQ (`V7`, `#1224`; `phenix/refinement/fsr/preprocess.py:394–417, 730–736, 837–840` vs. `phenix_html/rst_files/faqs/refine.txt:444–448, 460–478`):**

When neither explicit isotropic nor anisotropic selection strings are supplied, `preprocess.py:837–840` preserves the input model's per-scatterer isotropic/anisotropic flags subject to the preceding guards (without automatically promoting isotropic atoms to anisotropic).

These manual guidelines are not automatic code rules, and the `1.5 Å` vs. `1.7 Å` discrepancy is retained as a static observation without choosing a policy.

Source eligibility in `task_table.py` does not guarantee water placement below `2.8 Å` or establish a verified runtime no-op above `2.8 Å`.
10. **Separate XYZ and ADP target-weight optimization behavior (`V1`, `#1218`, `V2`, `#1219`, `V7`, `#1224`; `mmtbx/refinement/weights_params.py:1–104`, `phenix/refinement/xyz_reciprocal_space.py:274–288, 385–400, 452–487`, `mmtbx/refinement/adp_refinement.py:276–301, 325–330`, `phenix_html/rst_files/faqs/refine.txt:185–188`):**
    - `weights_params.py:5–104` defines five half-open `[d_min, d_max)` bins (`[0.0, 1.5)`, `[1.5, 2.0)`, `[2.0, 2.5)`, `[2.5, 3.5)`, `[3.5, 1e6)`) of **result-selection criteria** (`bonds_rmsd`, `angles_rmsd`, `r_free_minus_r_work`, `r_free_range_width`, `mean_diff_b_iso_bonded_fraction`, `min_diff_b_iso_bonded`), **not** trial-weight grids.
    - **XYZ weight optimization (`xyz_reciprocal_space.py`):** Trial-weight grids are built from `default_weight` at `:385–400`; result selection looks up the five-bin `weights_params.py` criteria and user overrides at `:471–487` and divides percentage-point gap/tolerance values by `100.` in `_select_best` (`:274–288`). By contrast, bundled FAQ `refine.txt:185–188` paraphrases skipping when `R-work` and `R-free` are close (without a numeric `0.01`) or when `R-free` is *greater* than `R-work`—a genuine opposite-sign wording disagreement between code and FAQ.

Thus `3.0 Å` is a distinct ADP weight-selection boundary.

### 3.2 Candidate Profile Dimensions and Historical-Configuration Boundaries (`C6`, `N1`, `N6`)

Any candidate resolution-conditioned profile (`Arm 3b` in `#1048`) or parameter-sensitivity factor must specify its settings across six dimensions while distinguishing (i) inspected static source defaults, (ii) uninspected runtime implementation paths, and (iii) scientific test hypotheses:

1. **ADP and TLS parameterization:** Isotropic vs. explicit macromolecular/solvent anisotropic selections (`adp.individual.anisotropic`), `main.switch_to_isotropic_high_res_limit`, and `tls` group refinement.
2. **Hydrogen and protonation policy:** Preserving input H/D vs. pre-building hydrogens (`phenix.ready_set` / `reduce`), `hydrogens.refine` (`riding` vs. `individual` vs. `auto`), electron-cloud vs. nuclear conventions, and `main.ias`.
3. **Ordered solvent policy:** `main.ordered_solvent`, `ordered_solvent.low_resolution`, and `ordered_solvent.mode`.
4. **Restraint dictionaries, NCS, reference-model, and secondary-structure restraints:** `restraints.use_cdl` vs. static Engh & Huber / CCP4 `$CLIBD_MON`, ligand CIFs, `pdb_interpretation.c_beta_restraints`, `pdb_interpretation.nonbonded_weight`, torsion/cartesian NCS, secondary-structure restraints, and reference-model restraints.
5. **Target-weight policy:** Heuristic weights vs. `optimize_xyz_weight` / `optimize_adp_weight` (accounting for the `r_free < r_work or abs(r_free - r_work) < 0.01` XYZ skip rule, `force_optimize_weights`, the `3.0 Å` ADP branch, and low-resolution `special_case` preconditions).
6. **Occupancy, alternate conformers, and dataset applicability covariates:** Altloc completeness, ligand/ion occupancy groups, and `T13` data-quality covariates (twinning, tNCS, anisotropy, completeness).

**Arm compatibility and historical motivation boundaries (`C6`, `N1`, `N6`, `#1226`, `#1231`):**
- Never silently apply performance-modifying steps (`phenix.ready_set` protonation or `ordered_solvent=True`) to the out-of-box default arm (`Arm 3a` in `#1048`); configured fixed profiles (`Arm 3b`) must be evaluated as separate arms with no pre-assumed performance improvement.
