# Question-Based Guide to Macromolecular Structure Tools and Measurements

This guide organizes the repository's 17 macromolecular crystallography, cryo-EM, NMR, and structure-prediction tasks (`T01`–`T17` in [`ref/catalog.yaml`](catalog.yaml)) around the **scientific questions** a structural biologist or automated evaluation harness needs to answer when assessing a model or a before/after refinement workflow.

Rather than treating tool outputs as interchangeable pass/fail numbers, this guide syntheses [`ref/catalog.yaml`](catalog.yaml), [`ref/tool_recommendations.yaml`](tool_recommendations.yaml), [`ref/tool_assumptions.yaml`](tool_assumptions.yaml), [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml), [`ref/structural_criteria.yaml`](structural_criteria.yaml), [`ref/oracle_tools.md`](oracle_tools.md), and [`ref/quality_reporting.md`](quality_reporting.md) across **four distinct epistemic layers**:

1. **Documented capability**: What the task catalog and upstream primary tool documentation define as the observable, producer, and mathematical convention.
2. **Runnable local integration**: Which CLI binaries, Python packages, and repository wrapper scripts (`scripts/gemmi_rfactor.py`, `scripts/t13_data_quality.py`, `scripts/t15_ss_agreement.py`, `scripts/t16_interface_quality.py`, `scripts/t17_nmr_ensemble.py`, `scripts/t17_restraint_summary.py`, `scripts/checkmymetal_local.py`, `scripts/audit_1sar_retained_evidence.py`, `scripts/assess_refinement.py`) are wired and executable in this repository, and what external installations (`PHENIX 2.0-5936`, `CCP4 9.0.015`, `OST`, `TM-align`, `US-align`, standalone `reduce`/`probe`, `gemmi`) are resolved via `scripts/toolchain.py`.
3. **Retained independent evidence**: What empirical measurements are actually stored on disk in `data/coscientists/openscientist/EVAL_*.yaml` and `data/examples/eval/EVAL_*.yaml` (`EVAL_*`), `data/coscientists/openscientist/QDS_*.yaml` and `data/examples/qds/QDS_*.yaml` (`QDS_*`), the 21-row registry inventory [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml), and `ref/research/data/`, including explicit deliberate oracle gaps, missing-artifact waivers, and stopped or access-blocked campaigns.
4. **Calibrated interpretation vs informational reporting**: Which clauses in [`ref/thresholds_and_standards.md`](thresholds_and_standards.md) (§1–§6) and [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml) (`policy_state` and `evidence_state` per component) have retained benchmark or literature support, which recommendations have active capability corrections or suspensions in [`ref/tool_recommendations.yaml`](tool_recommendations.yaml), and why before/after comparisons remain **informational** unless bound to an adopted `StructuralQualityCriterion` (`pass_criterion_bindings` is currently `[]` across all retained `EVAL_*.yaml` and `QDS_*.yaml` records under [`schemas/protstruct_review.yaml`](../schemas/protstruct_review.yaml)).

## 2. Epistemic Framework: Four Layers of Tool & Measurement Evidence

Every tool recommendation and measurement in this repository must be interpreted across four explicit layers:

```
┌────────────────────────────────────────────────────────────────────────────┐
│ Layer 1: Documented Capability (`ref/catalog.yaml`, primary tool manuals)  │
│ Defines the intended observable, mathematical formula, and candidate tools │
└──────────────────────────────────────┬─────────────────────────────────────┘
                                       ▼
┌────────────────────────────────────────────────────────────────────────────┐
│ Layer 2: Runnable Local Integration (`scripts/*.py`, `.venv`, CLI paths)   │
│ Verifies which binary/script actually executes on the workstation and what │
│ flags/inputs it requires (`ref/tool_recommendations.yaml`)                 │
└──────────────────────────────────────┬─────────────────────────────────────┘
                                       ▼
┌────────────────────────────────────────────────────────────────────────────┐
│ Layer 3: Retained Independent Evidence (`EVAL_*`, `QDS_*`, `data/*.json`)  │
│ Records exact input SHA-256 digests, tool versions, sample sizes, and      │
│ explicit gaps/waivers (`ref/threshold_evidence_status.yaml`)               │
└──────────────────────────────────────┬─────────────────────────────────────┘
                                       ▼
┌────────────────────────────────────────────────────────────────────────────┐
│ Layer 4: Calibrated Interpretation vs Informational Reporting              │
│ Applies active assumptions (`ref/tool_assumptions.yaml`) and separates     │
│ empirically calibrated tolerances from uncalibrated/informational metrics  │
└────────────────────────────────────────────────────────────────────────────┘
```

### Critical Rules When Crossing Layers
- **Do not infer runnable capability from a catalog name**: Two catalog entries previously assigned capabilities that the underlying CLI binary does not implement (`gemmi validate` does not compute bond/angle/planarity RMSD, chirality counts, $\omega$ flips, or Wilson $B$, corrected under `#785`; `ProSMART` is a reference-dependent structural comparison tool and does not compute a single-model Top8000 Ramachandran-Z score, corrected under `#911`). Always consult [`ref/tool_recommendations.yaml`](tool_recommendations.yaml) for active `role: deprecated` or `role: suspended` records before invoking a tool.
- **Do not treat retained observations or waivers as substitutes for missing coordinates**: In `data/coscientists/openscientist/EVAL_1sar_cdba2c07_2026-09-23.yaml` and `data/coscientists/openscientist/QDS_1sar_cdba2c07_2026-09-23.yaml`, the packaged archive retains `data/1sar_final.pdb` (the round-4 model, `1sar_4_refine_001`) while `claude_iterations.log` and the narrative report describe round 7 (`1sar_7_refine_001`). Retaining round-4 coordinate and data audits (`data/coscientists/openscientist/retained_evidence_2026-09-23/coordinate_and_t13_audit.json` and `ref/research/data/refinement_assessment_1sar_and_controls_2026-10-18.json`) characterizes the retained artifact and proves the provenance gap, but does not validate the absent round-7 model.
- **Do not promote informational deltas into automated pass/fail verdicts without criterion bindings**: Across every retained `EVAL_*.yaml` and `QDS_*.yaml` record in `data/coscientists/openscientist/` and `data/examples/`, `pass_criterion_bindings` is currently `[]`. Before/after refinement assessments in [`scripts/assess_refinement.py`](../scripts/assess_refinement.py) therefore return `assessment_verdict_status: "informational"` via `resolve_verdict_status()` whenever `pass_criterion_bindings: []`.

## 3. Category 1: Experimental Fit & Data Quality (`T03`, `T04`, `T06`, `T08`, `T09`, `T12`, `T13`)

### Core Scientific Questions
1. *Does the atomic model agree with the experimental diffraction amplitudes (`T03`, `T06`) or cryo-EM density map (`T04`, `T06`, `T08`), and is the free-set gap ($R_{\text{free}} - R_{\text{work}}$ or $FSC_{\text{work}} - FSC_{\text{free}}$) free of overfitting?*
2. *What ceiling do the raw experimental reflections (`T13`) or cryo-EM half-maps (`T12`) place on achievable model quality?*
3. *Did initial placement via molecular replacement (`T09`) or map docking (`T08`) find a genuine solution before coordinate refinement?*

### Task-by-Task Breakdown

#### `T03` — Reciprocal-space refinement (X-ray)
- **Documented capability**: Evaluates X-ray crystallographic coordinate, B-factor, occupancy, and TLS refinement by `phenix.refine`, `phenix.den_refine`, `phenix.rosetta_refine`, and `phenix.amber`. Oracles: `REFMAC5 (CCP4)`, `BUSTER`, `Servalcat`, and `gemmi rmsz`.
- **Runnable local integration**:
  - **Open-source (`top_performing`)**: External `gemmi` (`0.7.5`, resolved via `scripts/toolchain.py` `gemmi_executable()`) computes calculated structure factors via `gemmi sfcalc` (`REC_T03_r_work_top_performing_2026_09_22`, `REC_T03_r_free_top_performing_2026_09_22`). [`scripts/assess_refinement.py`](../scripts/assess_refinement.py) (`:640–681, :1767–1775`) does not execute live $R$-factor calculations; it verifies the recorded `1SAR` observations (`0.1622 / 0.2136` on archived `1sar.mtz` and `1sar_final.mtz` in `data/coscientists/openscientist/cdba2c07-daff-4f60-ae96-12452b3a5fbb_artifacts.zip`) and replays the retained 22-structure control-cohort JSON summaries (`ref/research/data/negative_control_round3_bench.json`, `ref/research/data/negative_control_round4_recover.json`, `ref/research/data/negative_control_round10_recover.json`; `#937`).

## 7. Category 5: Prediction Confidence & Predicted-Model Processing (`T07`)

### Core Scientific Questions
1. *Which regions of an AlphaFold2, AlphaFold3, ESMFold, or RoseTTAFold starting model are confident enough to use as molecular-replacement (`T09`) or map-docking (`T08`) templates, and how should pLDDT values be converted into crystallographic pseudo-$B$ factors?*
2. *How do self-reported prediction confidence scores (`pLDDT`, `PAE`, `pTM`, `ipTM`) differ from experimental coordinate accuracy (`lDDT`, `TM-score`)?*

### Task-by-Task Breakdown

#### `T07` — Predicted-model processing
- **Documented capability**: Processes structure predictions by trimming low-confidence regions, converting pLDDT to pseudo-$B$ factors, and splitting compact domains (`phenix.process_predicted_model`, `phenix.predict_model`, `phenix.predict_and_build`). Catalog metrics: `T07_fraction_residues_retained_after_trim`, `T07_mean_plddt_pre_post`, `T07_b-factor_1_plddt²_correlation`, `T07_domain_count_vs_pae_oracle`, `T07_rmsd_of_processed_model_vs_reference_experimental`, `T07_predicted_tm_score`, `T07_interface_predicted_tm_score`, and `T07_prediction_ensemble_convergence`. Oracles: `pae_to_domains.py (Croll/Tronrud)`, `biotite AF parsers`, `colabfold domain-splitter`, `ChimeraX alphafold`, `QMEANDisCo`, `TM-align`, and `OpenStructure`.
- **Runnable local integration**: `biotite AF parsers` (`REC_T07_mean_plddt_pre_post_top_considered`, `REC_T07_fraction_residues_retained_after_trim_top_considered`, `REC_T07_predicted_tm_score_top_considered`, `REC_T07_interface_predicted_tm_score_top_considered`) for B-factor/mmCIF `ma_qa_metric_local` extraction (`T07_mean_plddt_pre_post`, `T07_fraction_residues_retained_after_trim`, `T07_b-factor_1_plddt²_correlation`, `T07_predicted_tm_score`, `T07_interface_predicted_tm_score`); `pae_to_domains.py` (`REC_T07_domain_count_vs_pae_oracle_top_considered`, `T07_domain_count_vs_pae_oracle`) for graph-clustering PAE matrices into rigid domains; `OpenStructure` (`ost`) and `TM-align` (`REC_T07_rmsd_of_processed_model_vs_reference_experimental_top_considered`, `T07_rmsd_of_processed_model_vs_reference_experimental`) for post-refinement comparison against experimental structures.
- **Retained independent evidence**: `T07_mean_plddt_pre_post` is `literature_consensus` in [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml) (`<= 1.0` pLDDT point when matching AF2 per-residue vs AF3 per-atom aggregation).
- **Calibrated interpretation vs informational reporting**:
  - **Self-confidence vs experimental truth**: `pLDDT`, `PAE`, `pTM`, and `ipTM` (`T07_mean_plddt_pre_post`, `T07_predicted_tm_score`, `T07_interface_predicted_tm_score`) are neural-network self-confidence estimates, **not** experimental validation metrics. They must never be cited as evidence that a refined model fits experimental X-ray or cryo-EM data.
  - **Empirical pseudo-$B$ conversion (`Baek et al. 2021` / `Oeffner et al. 2022`)**: `phenix.process_predicted_model` converts fractional `L = pLDDT / 100` into an empirical positional error estimate $\text{RMSD}_{\text{est}} = 1.5\text{ Å} \times \exp[4 \times (0.7 - L)]$ and isotropic $B_{\text{pseudo}} = \frac{8\pi^2}{3}\,\text{RMSD}_{\text{est}}^2$ (`T07_b-factor_1_plddt²_correlation`), trimming residues with $\text{pLDDT} < 70$ (`T07_fraction_residues_retained_after_trim`).

## 8. Category 6: Classification & Experimental-Restraint Specialization (`T15`, `T17`)

### Core Scientific Questions
1. *Does the model maintain a physically interpretable secondary-structure architecture and fold classification (`T15` `DSSP`, `STRIDE`, `biotite P-SEA`, `CATH`/`SCOPe`/`ECOD`), and when is cross-tool secondary-structure agreement interpretable?*
2. *For solution-NMR structures (`T17`), what is the conformer ensemble precision (ordered core vs disordered tails) and are experimental NOE/dihedral restraint violations absent?*

### Task-by-Task Breakdown

#### `T15` — Structural/domain classification
- **Documented capability**: Oracle-only task assigning secondary-structure states (`H`/`E`/`C`) and domain/fold classifications. Catalog metrics: `T15_secondary_structure_agreement`, `T15_secondary_structure_content`, `T15_secondary_structure_assignment`, `T15_structural_domain_assignment`, and `T15_fold_classification`. Oracles: `DSSP`, `STRIDE`, `biotite P-SEA`, `CATH`, `SCOPe`, and `ECOD`.
- **Runnable local integration**: Wired via [`scripts/t15_ss_agreement.py`](../scripts/t15_ss_agreement.py) comparing `mkdssp` (`4.5.6` / `4.6.1`, H-bond pattern definition mapped from 8-state to 3-state `H`/`E`/`C`, `REC_T15_secondary_structure_assignment_top_considered`, `T15_secondary_structure_assignment`) against `biotite.structure.annotate_sse` (`1.6.0` / `1.7.1`, `P-SEA` $\text{C}\alpha$ distance/dihedral algorithm).
- **Retained independent evidence**:
  - [`ref/research/tolerance_benchmark_ss_agreement.md`](research/tolerance_benchmark_ss_agreement.md) (`secondary_structure` in [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml), `status: denominator_unproven`), `data/coscientists/openscientist/EVAL_1sar_cdba2c07_2026-09-22.yaml`, and `data/coscientists/openscientist/EVIDENCE_1sar_cdba2c07_2026-09-22_t15.json`: **16 well-ordered X-ray baseline structures** (`mkdssp 4.6.1` vs `biotite 1.7.1` P-SEA 3-state agreement median `0.753`, range `0.679–0.850`, `4/16 >= 0.80`, DSSP `H+E` `0.458–0.784`) plus **4 degraded controls** (`2JZ4` model 1 disordered NMR at `0.7625` agreement / `0.371` `H+E`, and `1UBQ` with `0.5 Å`, `1.0 Å`, and `2.0 Å` Gaussian coordinate noise where `H+E` drops `0.105 -> 0.026 -> 0.000` while 3-state agreement rises `0.7368 -> 0.8816 -> 1.0000` due to mutual coil collapse), computed on the historical intersection of residues (`n_dssp`, `n_biotite`, and `n_dropped` not retained).
- **Calibrated interpretation vs informational reporting**:
  - **Active recommendations (`REC_T15_secondary_structure_agreement_top_considered_2026_09_22`, `REC_T15_secondary_structure_agreement_top_performing_2026_09_22`, `REC_T15_secondary_structure_content_top_considered`)**:
    1. `DSSP` `H+E` fraction $\ge 0.20$ (`T15_secondary_structure_content`) is a **provisional interpretability precondition** (preventing mutual coil-collapse inflation when coordinate noise destroys H-bonds and $\text{C}\alpha$ geometry), **not** a standalone model-quality cutoff.
    2. The `0.65` cross-method agreement expectation (`T15_secondary_structure_agreement`) is **provisional and non-gradeable** (`denominator_unproven`) pending exact-denominator recalibration under `#765` (the stopped `#765` campaign showed that `mkdssp` drops chains/residues with incomplete backbone atoms or hetero-linkages, creating denominator mismatches unless residue eligibility is frozen from inputs prior to assignment).
    3. The `>= 0.85` agent-vs-DSSP criterion in [`ref/structural_criteria.yaml`](structural_criteria.yaml) applies only when an agent emits per-residue secondary-structure labels.

#### `T17` — NMR ensemble/restraint validation
- **Documented capability**: Oracle-only task evaluating NMR conformer bundle precision, per-residue RMSF, and experimental distance/dihedral restraint violations. Catalog metrics: `T17_nmr_restraint_violation_summary` and `T17_nmr_ensemble_precision_rmsd`. Oracles: `wwPDB NMR validation`, `PROCHECK-NMR`, `RPF`, and `biotite ensemble`.
- **Runnable local integration**:
  - [`scripts/t17_nmr_ensemble.py`](../scripts/t17_nmr_ensemble.py) (`REC_T17_nmr_ensemble_precision_rmsd_top_considered`, `REC_T17_nmr_ensemble_precision_rmsd_top_performing`, `T17_nmr_ensemble_precision_rmsd`): Uses `biotite` (`superimpose`) to superpose each conformer's $\text{C}\alpha$ trace onto the **first model** (`ca[0]`), computes per-residue $\text{C}\alpha$ RMSF around the superposed ensemble mean coordinates, defines the ordered core solely by the fixed threshold `_ORDERED_CORE_RMSF_CUTOFF = 2.0` Å (`rmsf <= 2.0 Å`, without invoking `DSSP`), and emits ordered-core mean $\text{C}\alpha$ RMSF (`value`) alongside whole-chain mean and max $\text{C}\alpha$ RMSF with `pass_status: "informational"`.
  - [`scripts/t17_restraint_summary.py`](../scripts/t17_restraint_summary.py) (`REC_T17_nmr_restraint_violation_summary_top_considered`, `REC_T17_nmr_restraint_violation_summary_top_performing`, `T17_nmr_restraint_violation_summary`): Parses deposited wwPDB validation XML files for NOE distance (`> 0.5 Å`) and dihedral (`> 5°`) restraint violations.
- **Retained independent evidence**: `T17_nmr_ensemble_precision_rmsd` (`empirical_benchmark` in [`ref/thresholds_and_standards.md`](thresholds_and_standards.md) §3 across 5 NMR ensembles showing core-definition sensitivity `0.14–0.84 Å` vs whole-chain `up to 2.15 Å`; on the 10-conformer `1D3Z` ubiquitin ensemble, [`scripts/t17_nmr_ensemble.py`](../scripts/t17_nmr_ensemble.py) reports ordered-core mean $\text{C}\alpha$ RMSF `0.316 Å` over `74/76` residues with `rmsf <= 2.0 Å` vs whole-chain mean `0.428 Å` and max `5.9 Å`) and `T17_nmr_restraint_violation_summary` (`0` NOE violations $> 0.5\text{ Å}$ verified on `2N54`, while legacy entry `1D3Z` lacks deposited restraint XML attributes).
- **Calibrated interpretation vs informational reporting**: Following [`ref/thresholds_and_standards.md`](thresholds_and_standards.md) §3, cross-tool NMR ensemble precision agreement (`T17_nmr_ensemble_precision_rmsd`) is $|\Delta| \le 0.05\text{ Å}$ only when the ordered-core residue selection/cutoff is matched; single-structure ensemble RMSF values are **descriptive** (`pass_status: "informational"`) rather than graded against fixed quality tiers, and ordered-core precision (`0.316 Å` on `1D3Z` at the `2.0 Å` RMSF cutoff) must never be conflated with whole-chain RMSF (`0.428 Å` mean, `5.9 Å` max at the flexible C-terminus).
