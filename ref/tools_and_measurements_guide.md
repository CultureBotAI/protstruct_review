# Question-Based Guide to Macromolecular Structure Tools and Measurements

This guide organizes the repository's 17 macromolecular crystallography, cryo-EM, NMR, and structure-prediction tasks (`T01`–`T17` in [`ref/catalog.yaml`](catalog.yaml)) around the **scientific questions** a structural biologist or automated evaluation harness needs to answer when assessing a model or a before/after refinement workflow.

Rather than treating tool outputs as interchangeable pass/fail numbers, this guide syntheses [`ref/catalog.yaml`](catalog.yaml), [`ref/tool_recommendations.yaml`](tool_recommendations.yaml), [`ref/tool_assumptions.yaml`](tool_assumptions.yaml), [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml), [`ref/structural_criteria.yaml`](structural_criteria.yaml), [`ref/oracle_tools.md`](oracle_tools.md), and [`ref/quality_reporting.md`](quality_reporting.md) across **four distinct epistemic layers**:

1. **Documented capability**: What the task catalog and upstream primary tool documentation define as the observable, producer, and mathematical convention.
2. **Runnable local integration**: Which CLI binaries, Python packages, and repository wrapper scripts (`scripts/t13_data_quality.py`, `scripts/t15_ss_agreement.py`, `scripts/t16_interface_quality.py`, `scripts/t17_nmr_ensemble.py`, `scripts/t17_restraint_summary.py`, `scripts/checkmymetal_local.py`, `scripts/audit_1sar_retained_evidence.py`, `scripts/assess_refinement.py`) are wired and executable in this repository, and what external installations (`PHENIX 2.0-5936`, `CCP4 9.0.015`, `OST`, `TM-align`, `US-align`) are required.
3. **Retained independent evidence**: What empirical measurements are actually stored on disk in `data/coscientists/openscientist/EVAL_*.yaml` and `data/examples/eval/EVAL_*.yaml` (`EVAL_*`), `data/coscientists/openscientist/QDS_*.yaml` and `data/examples/qds/QDS_*.yaml` (`QDS_*`), [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml), and `ref/research/data/`, including explicit deliberate oracle gaps, missing-artifact waivers, and stopped or access-blocked campaigns.
4. **Calibrated interpretation vs informational reporting**: Which metrics have empirically backed or literature-consensus tolerances in [`ref/thresholds_and_standards.md`](thresholds_and_standards.md) and [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml), which metrics have active capability corrections or suspensions in [`ref/tool_recommendations.yaml`](tool_recommendations.yaml), and why before/after comparisons remain **informational** unless bound to an adopted `StructuralQualityCriterion` (`pass_criterion_bindings` is currently `[]` across all retained `EVAL_*.yaml` and `QDS_*.yaml` records under [`schemas/protstruct_review.yaml`](../schemas/protstruct_review.yaml)).

## 2. Epistemic Framework: Four Layers of Tool & Measurement Evidence

Every tool recommendation and measurement in this repository must be interpreted across four explicit layers:

```
┌────────────────────────────────────────────────────────────────────────────┐
│ Layer 1: Documented Capability (`ref/catalog.yaml`, primary tool manuals)  │
│ Defines the intended observable, mathematical formula, and candidate tools │
└──────────────────────────────────────┬─────────────────────────────────────┘
                                       ▼
┌────────────────────────────────────────────────────────────────────────────┐
│ Layer 2: Runnable Local Integration (`scripts/*.py`, `.venv`, CLI paths)   │
│ Verifies which binary/script actually executes on the workstation and what │
│ flags/inputs it requires (`ref/tool_recommendations.yaml`)                 │
└──────────────────────────────────────┬─────────────────────────────────────┘
                                       ▼
┌────────────────────────────────────────────────────────────────────────────┐
│ Layer 3: Retained Independent Evidence (`EVAL_*`, `QDS_*`, `data/*.json`)  │
│ Records exact input SHA-256 digests, tool versions, sample sizes, and      │
│ explicit gaps/waivers (`ref/threshold_evidence_status.yaml`)               │
└──────────────────────────────────────┬─────────────────────────────────────┘
                                       ▼
┌────────────────────────────────────────────────────────────────────────────┐
│ Layer 4: Calibrated Interpretation vs Informational Reporting              │
│ Applies active assumptions (`ref/tool_assumptions.yaml`) and separates     │
│ empirically calibrated tolerances from uncalibrated/informational metrics  │
└────────────────────────────────────────────────────────────────────────────┘
```

### Critical Rules When Crossing Layers
- **Do not infer runnable capability from a catalog name**: Two catalog entries previously assigned capabilities that the underlying CLI binary does not implement (`gemmi validate` does not compute bond/angle/planarity RMSD, chirality counts, $\omega$ flips, or Wilson $B$, corrected under `#785`; `ProSMART` is a reference-dependent structural comparison tool and does not compute a single-model Top8000 Ramachandran-Z score, corrected under `#911`). Always consult [`ref/tool_recommendations.yaml`](tool_recommendations.yaml) for active `role: deprecated` or `role: suspended` records before invoking a tool.
- **Do not treat retained observations or waivers as substitutes for missing coordinates**: In `data/coscientists/openscientist/EVAL_1sar_cdba2c07_2026-09-23.yaml` and `data/coscientists/openscientist/QDS_1sar_cdba2c07_2026-09-23.yaml`, the packaged archive retains `data/1sar_final.pdb` (the round-4 model, `1sar_4_refine_001`) while `claude_iterations.log` and the narrative report describe round 7 (`1sar_7_refine_001`). Retaining round-4 coordinate and data audits (`data/coscientists/openscientist/retained_evidence_2026-09-23/coordinate_and_t13_audit.json` and `ref/research/data/refinement_assessment_1sar_and_controls_2026-10-18.json`) characterizes the retained artifact and proves the provenance gap, but does not validate the absent round-7 model.
- **Do not promote informational deltas into automated pass/fail verdicts without criterion bindings**: Across every retained `EVAL_*.yaml` and `QDS_*.yaml` record in `data/coscientists/openscientist/` and `data/examples/`, `pass_criterion_bindings` is currently `[]`. Before/after refinement assessments in [`scripts/assess_refinement.py`](../scripts/assess_refinement.py) therefore return `assessment_verdict_status: "informational"` via `resolve_verdict_status()` whenever `pass_criterion_bindings: []`.

## 3. Category 1: Experimental Fit & Data Quality (`T03`, `T04`, `T06`, `T08`, `T09`, `T12`, `T13`)

### Core Scientific Questions
1. *Does the atomic model agree with the experimental diffraction amplitudes (`T03`, `T06`) or cryo-EM density map (`T04`, `T06`, `T08`), and is the free-set gap ($R_{\text{free}} - R_{\text{work}}$ or $FSC_{\text{work}} - FSC_{\text{free}}$) free of overfitting?*
2. *What ceiling do the raw experimental reflections (`T13`) or cryo-EM half-maps (`T12`) place on achievable model quality?*
3. *Did initial placement via molecular replacement (`T09`) or map docking (`T08`) find a genuine solution before coordinate refinement?*

### Task-by-Task Breakdown

#### `T03` — Reciprocal-space refinement (X-ray)
- **Documented capability**: Evaluates X-ray crystallographic coordinate, B-factor, occupancy, and TLS refinement by `phenix.refine`, `phenix.den_refine`, `phenix.rosetta_refine`, and `phenix.amber`. Catalog metrics: `T03_r_work`, `T03_r_free`, `T03_r_free_minus_r_work`, `T03_bond_rmsd`, `T03_angle_rmsd`, `T03_clashscore`, `T03_ramachandran_outliers_favored`, and `T03_rotamer_outliers`. Oracles: `REFMAC5 (CCP4)`, `BUSTER`, `Servalcat`, and `gemmi rmsz`.
- **Runnable local integration**:
  - **Open-source (`top_performing`)**: `gemmi sfcalc` (`gemmi 0.7.5`, installed in `.venv`) computes structure factors (`F_calc`) from atomic coordinates (`REC_T03_r_work_top_performing_2026_09_22`, `REC_T03_r_free_top_performing_2026_09_22`). Plain unmasked `gemmi sfcalc` lacks a bulk-solvent mask or ML scaling, whereas [`scripts/gemmi_rfactor.py`](../scripts/gemmi_rfactor.py) runs `gemmi sfcalc --scale-to` (bulk-solvent + anisotropic scaling) followed by 10-shell work-set bin-wise isotropic rescaling. In [`scripts/assess_refinement.py`](../scripts/assess_refinement.py), both live `gemmi sfcalc --scale-to` + bin-rescaled observations on `1SAR` (`0.1622 / 0.2136` on archive members `1sar.mtz` and `1sar_final.mtz` in `data/coscientists/openscientist/cdba2c07-daff-4f60-ae96-12452b3a5fbb_artifacts.zip`) and the retained 22-structure control cohort `d_gemmi` values (`ref/research/data/negative_control_round3_bench.json`, `ref/research/data/negative_control_round4_recover.json`, `ref/research/data/negative_control_round10_recover.json`) are paired directly against `phenix.model_vs_data` and `REFMAC5` on identical reflections and free-R flags.
  - **All-considered (`top_considered`)**: `Servalcat` (`servalcat refine_xtal_norefmac` or `REFMAC5` via CCP4 `9.0.015`) computes bulk-solvent and ML-scaled $R_{\text{work}}$ / $R_{\text{free}}$ (`REC_T03_r_work_top_considered`, `REC_T03_r_free_top_considered`). Note `ASSUM_servalcat_refine_xtal_actually_refines`: plain `servalcat refine_xtal` performs coordinate refinement even at `--ncycle 0`; zero-cycle evaluation requires `REFMAC5` `ncyc 0` or `gemmi sfcalc`.
  - **Geometry cross-check**: `REC_T03_bond_angle_rmsd_top_considered_2026_09_27_capability_correction` replaces `gemmi validate` (deprecated) with `gemmi rmsz` + CCP4 monomer library (`CLIBD_MON`).
- **Retained independent evidence**:
  - `T03_r_work` and `T03_r_free` in [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml) and [`ref/research/tolerance_benchmark_r_offset.md`](research/tolerance_benchmark_r_offset.md): `empirical_benchmark` on the 5-structure crystallographic control cohort (`1ABA`, `1UBQ`, `3K0N`, `6LU7`, `1SAR`). Unmasked direct-summation `gemmi sfcalc` $R_{\text{work}}$ has a systematic $+0.105$ to $+0.181$ offset above bulk-solvent-corrected `phenix.refine` $R_{\text{work}}$ (`ASSUM_gemmi_sfcalc_r_work_offset_scope_2026_09_22`), and unscaled $R_{\text{free}}$ is retained as **informational** because 2 of 5 entries (`1ABA`, `6LU7`) exceed the $+0.18$ ceiling (`+0.2039`, `+0.1897`).
  - [`ref/research/tolerance_benchmark_refinement_deltas.md`](research/tolerance_benchmark_refinement_deltas.md): Same-subject `phenix.refine` (`2.0-5936`) vs `gemmi sfcalc` (`0.7.5`) across 5 structures (`ASSUM_phenix_refine_same_subject_r_factor_comparison_2026_09_22`).
  - `ref/research/data/refinement_assessment_1sar_and_controls_2026-10-18.json` (and [`ref/research/refinement_assessment_case_study_2026-10-18.md`](research/refinement_assessment_case_study_2026-10-18.md)): Paired before/after assessment across the retained `1SAR` OpenScientist run (`data/coscientists/openscientist/EVAL_1sar_cdba2c07_2026-09-23.yaml`) and all 5 22-structure sub-Å control cohorts (`unchanged_null`, `damaged_sa`, `damaged_dynamics`, `recovered_unprotonated_solvent`, `recovered_protonated_ordered_solvent`).
- **Calibrated interpretation vs informational reporting**:
  - Bulk-solvent-corrected $R_{\text{work}}$ / $R_{\text{free}}$ agreement between `phenix.refine` and `REFMAC5`/`Servalcat` is calibrated at $\le 0.015$ ($R_{\text{work}}$) and $\le 0.020$ ($R_{\text{free}}$), with $\Delta(R_{\text{free}} - R_{\text{work}}) \le 0.05$ (`ASSUM_refmac_solvent_modelling`, `ASSUM_servalcat_sigmaa_per_shell_only`).
  - Unmasked direct-summation `gemmi sfcalc` $R_{\text{work}}$ / $R_{\text{free}}$ is **informational** for absolute fit due to the missing bulk-solvent mask, while `scripts/gemmi_rfactor.py` (`gemmi sfcalc --scale-to` + 10-shell work-set bin rescaling) aligns closely with `phenix.model_vs_data` (`0.2136` vs `0.2116` $R_{\text{free}}$ on `1SAR`; median $|\Delta R_{\text{free}}^{\text{phenix}} - \Delta R_{\text{free}}^{\text{gemmi}}| \le 0.0011$ across the 22-structure control cohorts) and provides a deterministic, license-free relative delta ($\Delta R_{\text{work}}$, $\Delta R_{\text{free}}$) on identical reflections and free-R flags in [`scripts/assess_refinement.py`](../scripts/assess_refinement.py).

#### `T04` — Real-space refinement (map-based)
- **Documented capability**: Evaluates map-guided coordinate refinement (`phenix.real_space_refine`, `phenix.varref`). Catalog metrics: `T04_cc_mask`, `T04_cc_volume`, `T04_cc_peaks`, `T04_Per-residue_CC`, `T04_clashscore`, `T04_ramachandran_outliers_favored`, `T04_rotamer_outliers`, `T04_c_beta_deviations`, `T04_cablam_outliers`, and `T04_emringer_score`. Oracles: `Servalcat`, `ISOLDE (ChimeraX)`, `REFMAC real-space`, `Rosetta cryo_em_refinement`, and `MolProbity (gold)`.
- **Runnable local integration**: `REC_T04_cc_mask_top_considered`, `REC_T04_cc_volume_top_considered`, `REC_T04_cc_peaks_top_considered`, and `REC_T04_d_fsc_model_top_considered` recommend `Servalcat` (`servalcat fsc` / real-space correlation); geometry metrics (`REC_T04_clashscore_top_considered`, `REC_T04_ramachandran_favored_top_considered`) delegate to the `MolProbity (gold)` (`probe` + `reduce`) and `OpenStructure` / `gemmi` validators documented under `T05`.
- **Retained independent evidence**: `T04_cc_mask` in [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml) is `empirical_benchmark` across 12 cryo-EM structures (`n=12`, mean delta $+0.025 \pm 0.049$, max $|\Delta| = 0.088$, $r = 0.922$).
- **Calibrated interpretation vs informational reporting**: $CC_{\text{mask}}$ agreement within $\pm 0.05$ (`Servalcat` vs `phenix.map_model_cc`) is empirically calibrated; values $> 0.70$ at $\le 3.5\text{ Å}$ resolution indicate acceptable map-model fit, while before/after real-space refinement must verify that $\Delta CC_{\text{mask}} > 0$ is not bought at the expense of Ramachandran/rotamer/clashscore degradation.

#### `T06` — Model-vs-data statistics
- **Documented capability**: Computes one-shot model-vs-data agreement without modifying coordinates (`phenix.model_vs_data`, `phenix.mtriage`, `phenix.fmodel`, `phenix.map_correlations`). Catalog metrics: `T06_r_work_r_free_recomputed`, `T06_cc_mask_cc_volume_cc_peaks`, `T06_per-residue_real-space_cc`, `T06_fsc_model-map_at_0_5_and_0_143`, `T06_overall_isotropic_anisotropic_b`, and `T06_ anomalous_peak_heights`. Oracles: `CCP4 sfcheck`, `refmac -hklin`, `Servalcat`, `gemmi sfcalc`, `PDB-REDO`, `FSC-Q`, `edstats`, and `ctruncate`.
- **Runnable local integration**:
  - `gemmi sfcalc` + `gemmi` B-factor inspection (`scripts/assess_refinement.py`) for open-source coordinate/reflection checks.

- **Retained independent evidence**: `T02_per-residue_ca_distance` (`literature_consensus`, $\le 0.01\text{ Å}$ on identical atom pairs) and `T02_chi1_chi2_rotamer_class_agreement` (`literature_consensus`, $\ge 90\%$ agreement on ordered core residues) in [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml); atom-key-matched shift distributions ($p_{50}$, $p_{95}$, max $\text{C}\alpha$ and heavy-atom shifts) on `1SAR` (`data/coscientists/openscientist/retained_evidence_2026-09-23/coordinate_and_t13_audit.json`) and across the 5 22-structure control cohorts in `ref/research/data/refinement_assessment_1sar_and_controls_2026-10-18.json`.

#### `T11` — Loop / missing-region fitting
- **Documented capability**: Builds or rebuilds missing loops and insertions/deletions (`phenix.fit_loops`, `phenix.fix_insertions_deletions`, `phenix.rebuild_model`). Catalog metrics: `T11_loop_completeness`, `T11_loop_real-space_cc`, `T11_loop_ca_rmsd_to_reference`, `T11_loop_ramachandran_favored_outliers`, `T11_loop_clashscore`, and `T11_anchor_deviation`. Oracles: `Coot Fit Loop (DB/Rama-search)`, `ModLoop`, `Rosetta loopmodel`, `RosettaCM`, `edstats`, `MolProbity (gold)`, and `gemmi align`.
- **Runnable local integration**: `edstats` / `Servalcat` (`REC_T11_loop_rscc_top_considered`) for loop-only real-space CC; `gemmi align` (`REC_T11_rmsd_rebuilt_vs_reference_loop_top_considered`) for anchor-superposed loop $\text{C}\alpha$ RMSD; `MolProbity (gold)` (`REC_T11_ramachandran_favored_within_loop_top_considered`, `REC_T11_new_outliers_top_considered`) for loop-residue Ramachandran/clash validation.
- **Retained independent evidence**: `T11_loop_real-space_cc` (`literature_consensus`, loop $CC_{\text{mask}} \ge 0.60$) and `T11_loop_ca_rmsd_to_reference` (`literature_consensus`, $\le 2.0\text{ Å}$ vs reference) in [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml).
- **Calibrated interpretation vs informational reporting**: Any rebuilt loop must be checked locally (not diluted into whole-protein averages): anchor peptide bonds must close ($\text{C}\text{--}\text{N} < 1.5\text{ Å}$), loop density correlation must be $\ge 0.60$ (or explicitly left unmodeled if disordered), and loop residues must have $0$ Ramachandran outliers.

## 6. Category 4: Sites, Ligands & Biological Interfaces (`T10`, `T16`)

### Core Scientific Questions
1. *Are bound ligands, cofactors, metals, and active-site waters supported by experimental density (`T10` ligand real-space CC, RSZD, occupancy, B-factor ratio), strain-free covalent geometry (`Mogul`/`REEL`), and valid metal coordination geometry (`CheckMyMetal`)?*
2. *Are biological quaternary interfaces and buried surface areas (`T16` PISA/biotite BSA, $\Delta^i G$, `DockQ`) preserved across refinement or modeling?*

### Task-by-Task Breakdown

#### `T10` — Ligand fitting
- **Documented capability**: Fits and validates small-molecule ligands, cofactors, and metal ions (`phenix.ligandfit`, `phenix.ligand_pipeline`, `phenix.find_all_ligands`, `phenix.eLBOW`, `phenix.REEL`, `phenix.guided_ligand_replacement`). Catalog metrics: `T10_ligand_real-space_cc`, `T10_ligand_rmsd_to_reference`, `T10_rszd_rszo_edstats`, `T10_ligand_bond_angle_rmsz_mogul_z-score`, `T10_ligand_protein_clash_count`, `T10_occupancy_and_b-factor_ratio_vs_pocket`, and `T10_metal_coordination_geometry`. Oracles: `Coot Find Ligand`, `AFITT (OpenEye)`, `rhofit (Global Phasing)`, `CCP4 libcheck/acedrg`, `edstats`, `MolProbity (gold)`, `CheckMyMetal`, `protstruct local metal geometry screen`, `gemmi align`, and `gemmi script`.
- **Runnable local integration**:
  - **Active-site & ligand coordinate/B-factor audit**: [`scripts/audit_1sar_retained_evidence.py`](../scripts/audit_1sar_retained_evidence.py) and [`scripts/assess_refinement.py`](../scripts/assess_refinement.py) compute non-water heteroatom (`HETATM`) inventories (`SO4`, `CA`, `NA`, etc.), pocket-contact residue counts ($\le 4.0\text{ Å}$, `REC_T10_protein-ligand_hbond_count_top_considered`), pose RMSD (`REC_T10_rmsd_to_deposited_ligand_pose_top_considered`), and ligand-to-surrounding-protein $\langle B \rangle$ ratios (`REC_T10_ligand_b_vs_surroundings_top_considered`, `REC_T10_ligand_b_factor_mean_top_considered`).
  - **Local metal coordination screen**: [`scripts/checkmymetal_local.py`](../scripts/checkmymetal_local.py) (`REC_T10_ligand_element_identity_z_top_considered`, `REC_T10_ligand_element_identity_top_considered`) computes coordination numbers, donor-atom chemistry, bond-valence sums (`BVS`), and gRMSD without requiring the external CheckMyMetal web server (`ASSUM_checkmymetal_geometry_based`).
  - **Density difference metrics**: `edstats` (`REC_T10_ligand_rscc_top_considered`, `REC_T10_ligand_rsr_top_considered`) requires pre-computed $2mF_o - DF_c$ and $mF_o - DF_c$ columns (`ASSUM_edstats_needs_2fofc_dfofc_in_mtz`).
- **Retained independent evidence**:
  - `T10_ligand_real-space_cc` and `T10_ligand_rmsd_to_reference` are `literature_consensus` in [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml).
  - `data/coscientists/openscientist/EVAL_1sar_cdba2c07_2026-09-23.yaml`, `data/coscientists/openscientist/retained_evidence_2026-09-23/coordinate_and_t13_audit.json`, `data/examples/eval/EVAL_synth_active_site_2026-09-23.yaml` (`data/examples/qds/QDS_synth_active_site_2026-09-23.yaml`), and `ref/research/data/refinement_assessment_1sar_and_controls_2026-10-18.json` retain ligand/site audits on `1SAR` (packaged round-4 `A:97:SO4`, `A:98:CA`, `B:98:NA`, and `146` waters vs starting model `A:97:SO4`, `B:97:SO4`, `0` waters and deposited `1SAR` `A:97:SO4`, `B:97:SO4`, `138` waters).
- **Calibrated interpretation vs informational reporting**:
  - Ligand RSCC $\ge 0.80$ ($< 0.70$ questionable), `edstats` RSZD $< 3.0$ and RSZO $> 2.0$, and symmetry-aware heavy-atom pose RMSD $\le 1.0\text{ Å}$ (good) / $\le 2.0\text{ Å}$ (acceptable) are literature-consensus standards.
  - **Ligand $B$-factor ratio caveat**: As documented in [`ref/quality_reporting.md`](quality_reporting.md) (`T10_occupancy_and_b-factor_ratio_vs_pocket`), the ratio $\langle B_{\text{ligand}} \rangle / \langle B_{\text{pocket}} \rangle$ is an **informational** consistency check to be interpreted alongside RSCC, RSZD/RSZO, and occupancy—not a standalone $< 1.5$ pass/fail cutoff.

#### `T16` — Interface and assembly quality
- **Documented capability**: Oracle-only task evaluating biological assembly assignment, buried surface area (BSA), solvation energy ($\Delta^i G$), and multimeric contact conservation (`DockQ`). Catalog metrics: `T16_interface_buried_surface_area`, `T16_interface_delta_g_and_p-value`, `T16_dockq_score`, `T16_interface_clashscore`, and `T16_assembly_oligomeric_state_agreement`. Oracles: `PISA/PDBePISA`, `biotite SASA`, and `DockQ`.
- **Runnable local integration**: Wired via [`scripts/t16_interface_quality.py`](../scripts/t16_interface_quality.py) using `biotite SASA` (`shrake_rupley` at $1.4\text{ Å}$ probe radius), `DockQ` (`2.1.3` in `.venv/bin/DockQ`, `REC_T16_interface_dockq_score_top_considered`, `REC_T16_interface_dockq_score_top_performing`, `REC_T16_capri_interface_quality_class_top_considered`), and the PDBePISA REST API.
  - **Active convention & selection boundary (`#754`)**: `REC_T16_interface_buried_surface_area_top_considered_2026_09_22` and `REC_T16_interface_buried_surface_area_top_performing_2026_09_22` define two-sided BSA $= (\text{SASA}_A + \text{SASA}_B) - \text{SASA}_{AB} = 2 \times \text{PISA }\text{interface\_area}$. Importantly, `scripts/t16_interface_quality.py` filters `biotite` SASA to standard amino-acid polymers (`filter_amino_acids`), whereas the PDBePISA cache sums across all chains including waters and ligands ([`ref/research/tolerance_benchmark_interface_bsa.md`](research/tolerance_benchmark_interface_bsa.md)).
- **Retained independent evidence**:
  - `T16_interface_buried_surface_area` ([`ref/research/tolerance_benchmark_interface_bsa.md`](research/tolerance_benchmark_interface_bsa.md), `data/coscientists/openscientist/EVAL_1sar_cdba2c07_2026-09-21.yaml`, `data/coscientists/openscientist/EVIDENCE_1sar_cdba2c07_2026-09-21_bsa.json`, `data/coscientists/openscientist/EVIDENCE_1sar_cdba2c07_2026-09-21_dockq_AB_AB.json`, and `data/coscientists/openscientist/EVIDENCE_1sar_cdba2c07_2026-09-21_dockq_AB_BA.json`): `empirical_benchmark` across 3 homodimers (`1GZX`, `2HHB`, `4HHB`, 18 chain pairs; protein-only pairs agree within `max(3% of mean, 30 Å²)`, while heme/water-inclusive PISA rows diverge by up to $47.9\%$).
  - `T16_dockq_score`: `literature_consensus` (`DockQ >= 0.23` acceptable, `>= 0.49` medium, `>= 0.80` high; Basu & Wallner 2016) with explicit chain-mapping bijection required for homo-oligomers.
- **Calibrated interpretation vs informational reporting**: When assessing refinement of multimeric complexes, run `DockQ` and two-sided `biotite` BSA on identical polymer chain selections to ensure subunit interfaces were not pried apart or compressed during refinement.

## 7. Category 5: Prediction Confidence & Predicted-Model Processing (`T07`)

### Core Scientific Questions
1. *Which regions of an AlphaFold2, AlphaFold3, ESMFold, or RoseTTAFold starting model are confident enough to use as molecular-replacement (`T09`) or map-docking (`T08`) templates, and how should pLDDT values be converted into crystallographic pseudo-$B$ factors?*
2. *How do self-reported prediction confidence scores (`pLDDT`, `PAE`, `pTM`, `ipTM`) differ from experimental coordinate accuracy (`lDDT`, `TM-score`)?*

### Task-by-Task Breakdown

#### `T07` — Predicted-model processing
- **Documented capability**: Processes structure predictions by trimming low-confidence regions, converting pLDDT to pseudo-$B$ factors, and splitting compact domains (`phenix.process_predicted_model`, `phenix.predict_model`, `phenix.predict_and_build`). Catalog metrics: `T07_plddt_mean_and_per-residue_distribution`, `T07_pae_domain_count_and_boundaries`, `T07_ptm_iptm`, `T07_residues_retained_after_trimming`, `T07_converted_b-factor_distribution`, and `T07_rmsd_of_trimmed_domains_to_deposited_refined_target`. Oracles: `pae_to_domains.py (Croll/Tronrud)`, `biotite AF parsers`, `colabfold domain-splitter`, `ChimeraX alphafold`, `QMEANDisCo`, `TM-align`, and `OpenStructure`.
- **Runnable local integration**: `biotite AF parsers` (`REC_T07_mean_plddt_pre_post_top_considered`, `REC_T07_fraction_residues_retained_after_trim_top_considered`, `REC_T07_predicted_tm_score_top_considered`, `REC_T07_interface_predicted_tm_score_top_considered`) for B-factor/mmCIF `ma_qa_metric_local` extraction; `pae_to_domains.py` (`REC_T07_domain_count_vs_pae_oracle_top_considered`) for graph-clustering PAE matrices into rigid domains; `OpenStructure` (`ost`) and `TM-align` (`REC_T07_rmsd_of_processed_model_vs_reference_experimental_top_considered`) for post-refinement comparison against experimental structures.
- **Retained independent evidence**: `T07_plddt_mean_and_per-residue_distribution` is `literature_consensus` in [`ref/threshold_evidence_status.yaml`](threshold_evidence_status.yaml) (`<= 1.0` pLDDT point when matching AF2 per-residue vs AF3 per-atom aggregation).
- **Calibrated interpretation vs informational reporting**:
  - **Self-confidence vs experimental truth**: `pLDDT`, `PAE`, `pTM`, and `ipTM` are neural-network self-confidence estimates, **not** experimental validation metrics. They must never be cited as evidence that a refined model fits experimental X-ray or cryo-EM data.
  - **Empirical pseudo-$B$ conversion (`Baek et al. 2021` / `Oeffner et al. 2022`)**: `phenix.process_predicted_model` converts fractional `L = pLDDT / 100` into an empirical positional error estimate $\text{RMSD}_{\text{est}} = 1.5\text{ Å} \times \exp[4 \times (0.7 - L)]$ and isotropic $B_{\text{pseudo}} = \frac{8\pi^2}{3}\,\text{RMSD}_{\text{est}}^2$, trimming residues with $\text{pLDDT} < 70$.

## 8. Category 6: Classification & Experimental-Restraint Specialization (`T15`, `T17`)

### Core Scientific Questions
1. *Does the model maintain a physically interpretable secondary-structure architecture and fold classification (`T15` `DSSP`, `STRIDE`, `biotite P-SEA`, `CATH`/`SCOPe`/`ECOD`), and when is cross-tool secondary-structure agreement interpretable?*
2. *For solution-NMR structures (`T17`), what is the conformer ensemble precision (ordered core vs disordered tails) and are experimental NOE/dihedral restraint violations absent?*

### Task-by-Task Breakdown

#### `T15` — Structural/domain classification
- **Documented capability**: Oracle-only task assigning secondary-structure states (`H`/`E`/`C`) and domain/fold classifications. Catalog metrics: `T15_secondary_structure_agreement`, `T15_secondary_structure_content`, `T15_domain_count_and_boundaries`, and `T15_fold_classification_match`. Oracles: `DSSP`, `STRIDE`, `biotite P-SEA`, `CATH`, `SCOPe`, and `ECOD`.
- **Runnable local integration**: Wired via [`scripts/t15_ss_agreement.py`](../scripts/t15_ss_agreement.py) comparing `mkdssp` (`4.5.6` / `4.6.1`, H-bond pattern definition mapped from 8-state to 3-state `H`/`E`/`C`, `REC_T15_secondary_structure_assignment_top_considered`) against `biotite.structure.annotate_sse` (`1.6.0` / `1.7.1`, `P-SEA` $\text{C}\alpha$ distance/dihedral algorithm).
- **Retained independent evidence**:
  - [`ref/research/tolerance_benchmark_ss_agreement.md`](research/tolerance_benchmark_ss_agreement.md), `data/coscientists/openscientist/EVAL_1sar_cdba2c07_2026-09-22.yaml`, and `data/coscientists/openscientist/EVIDENCE_1sar_cdba2c07_2026-09-22_t15.json`: 17-structure empirical benchmark (`13` baseline structures with `DSSP H+E >= 0.20`, range `0.660`–`0.921`, mean `0.785`; `4` control/edge structures `1GZX`, `2HHB`, `4HHB`, `2N54`).
- **Calibrated interpretation vs informational reporting**:
  - **Active recommendations (`REC_T15_secondary_structure_agreement_top_considered_2026_09_22`, `REC_T15_secondary_structure_agreement_top_performing_2026_09_22`, `REC_T15_secondary_structure_content_top_considered`)**:
    1. `DSSP` `H+E` fraction $\ge 0.20$ is a **provisional interpretability precondition** (identifying whether a model has enough regular secondary structure for 3-state `mkdssp` vs `biotite P-SEA` agreement to be meaningful), **not** a model-quality cutoff (small coil-rich peptides like `2N54` legitimately have `< 0.20` `H+E`).
    2. The historical `0.65` cross-method agreement threshold (`T15_secondary_structure_agreement`) is **non-gradeable** pending exact-denominator recalibration under `#765` (the stopped `#765` campaign showed that `mkdssp` drops chains/residues with incomplete backbone atoms or hetero-linkages, creating denominator mismatches unless eligibility is frozen from inputs prior to assignment).
    3. The `>= 0.85` agent-vs-DSSP criterion (`T15_ss_q3_agreement` in `ref/structural_criteria.yaml`) applies only when an agent emits per-residue secondary-structure labels.

#### `T17` — NMR ensemble/restraint validation
- **Documented capability**: Oracle-only task evaluating NMR conformer bundle precision, per-residue RMSF, and experimental distance/dihedral restraint violations. Catalog metrics: `T17_ensemble_backbone_rmsd`, `T17_per_residue_rmsf`, `T17_noe_distance_restraint_violations`, `T17_dihedral_restraint_violations`, `T17_rpf_recall_precision_f_measure`, and `T17_ensemble_ramachandran_clashscore`. Oracles: `wwPDB NMR validation`, `PROCHECK-NMR`, `RPF`, and `biotite ensemble`.
- **Runnable local integration**:
  - [`scripts/t17_nmr_ensemble.py`](../scripts/t17_nmr_ensemble.py) (`REC_T17_nmr_ensemble_precision_rmsd_top_considered`, `REC_T17_nmr_ensemble_precision_rmsd_top_performing`): Uses `biotite` to superpose all conformers onto medoid/model 1, defines ordered core residues (`RMSF <= 1.0 Å` or `DSSP` `H`/`E`), and computes both ordered-core and all-residue $\text{C}\alpha$ RMSD/RMSF.
  - [`scripts/t17_restraint_summary.py`](../scripts/t17_restraint_summary.py) (`REC_T17_nmr_restraint_violation_summary_top_considered`, `REC_T17_nmr_restraint_violation_summary_top_performing`): Parses deposited wwPDB validation XML files for NOE distance (`> 0.5 Å`) and dihedral (`> 5°`) restraint violations.
- **Retained independent evidence**: `T17_ensemble_backbone_rmsd` (`empirical_benchmark` on `1D3Z` 10-model ubiquitin ensemble and `2N54` 20-model peptide ensemble) and `T17_noe_distance_restraint_violations` (`literature_consensus`, `0` violations $> 0.5\text{ Å}$ verified on `2N54`, while noting that legacy entry `1D3Z` lacks deposited restraint XML sections).
- **Calibrated interpretation vs informational reporting**: Ordered-core ensemble $\text{C}\alpha$ RMSD ($< 0.5\text{ Å}$ well-defined, $0.5$–$1.0\text{ Å}$ acceptable, $> 1.5\text{ Å}$ poorly defined) must never be conflated with whole-chain RMSD, which is $3\times$–$5\times$ larger due to flexible termini (`1D3Z` core $0.244\text{ Å}$ vs all-residue $1.106\text{ Å}$).
